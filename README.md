## 📌 주요 특징
1. **반응형 웹 디자인**: PC, 태블릿, 모바일 스마트폰 전 기종 지원 (하단 퀵 내비게이션 바 탑재)
2. **5대 카테고리 구성**:
   - **홈**: 환영사 및 행사 개요 요약, 감성 인트로 영상 모달 팝업
   - **과정소개**: '부드럽' 과정 의미(쉼·감사·동행), 1박 2일 상세 일정표, 오시는 길 & 지도 바로가기
   - **프로그램**: 군위 사유원, 화본역 & 옛날옛적에 엄마아빠, 오아르미술관, 황리단길 부부 자유투어 (영상 및 필터 기능)
   - **숙소**: 5성급 특급 호텔 '경주 힐튼호텔' 객실, 프리미엄 조식 뷔페, 천연 온천 사우나 부대시설 안내
   - **기타 사항**: 운영본부 담당자 전화/문자 바로걸기, 비상 연락망, 필수 준비물, FAQ 아코디언
3. **고즈넉한 감성 디자인**: 오트밀/세이지/우드 톤의 따뜻하고 편안한 힐링 비주얼
4. **힐링 사운드(BGM)**: Web Audio API 기반의 은은한 자연 차임벨 소리 재생 기능

## 🚀 GitHub Pages 무료 호스팅 배포 방법
본 저장소(Repository)는 GitHub Pages를 통해 별도의 서버 비용 없이 평생 무료로 웹사이트를 전 세계에 공개할 수 있습니다:

1. GitHub 저장소 상단의 **[Settings]** 탭을 클릭합니다.
2. 좌측 메뉴에서 **[Pages]** 메뉴를 선택합니다.
3. **Build and deployment > Branch** 항목에서:
   - `None`을 **`main`** 브랜치로 변경합니다.
   - 폴더는 **`/(root)`** 로 두고 **[Save]** 버튼을 누릅니다.
4. 약 1~2분 후 다음과 같은 주소로 공식 웹사이트가 배포됩니다:
   👉 **`https://psw71012232.github.io/TORAY/`**

## 💻 로컬 실행 방법 (Windows)
외부 프로그램 설치 없이 윈도우 기본 PowerShell로 즉시 실행 가능합니다:

```powershell
powershell -ExecutionPolicy Bypass -File server.ps1
```
실행 후 웹 브라우저에서 `http://localhost:8080` 으로 접속합니다.
